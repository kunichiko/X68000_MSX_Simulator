# MC68000 版の検証手順

この移植には、改修の正しさを機械的に確かめるための条件アセンブルが用意してあります。
いずれも通常のビルドには入らず、指定したときだけ有効になります。

```
make BUILD_DIR=bv SJIS_DIR=bv/s EXE_DIR=bv ASEXTRA="-s <スイッチ>"
```

## スイッチの一覧

| スイッチ | 何を確かめるか |
| --- | --- |
| `NOFAST` | 高速経路を使わず従来と同じ経路だけで動かす。**改修前と挙動が変わらないことの基準** |
| `FORCEFAST` | 高速経路を常に使う |
| `EDGEALWAYS` | **すべての命令をページ境界またぎの経路へ通す。**通常は稀にしか通らない経路を全数試す |
| `CHECKPC` | 毎命令、命令ポインタとページ内位置の対応が保たれているか検査し、破れていたら `illegal` を実行する |
| `CHECKMAIN` | 高速版を選んだのに従来経路へ来ていないか検査する |
| `CHECKA0` / `POISON_D3` | レジスタの使用規約が破られていないか検査する |
| `CHECKVKIND` | ＶＲＡＭ書き込み先の表引きが、従来の比較と同じ答えを出すか毎回突き合わせる |
| `FASTAUDIT` | `EI` 直後の割り込み抑止について、新旧 2 通りの判定が高速経路上で一致するか突き合わせる |

`illegal` を踏んだ位置は、`make debug` で作る `ms_debug.x` が例外を捕捉して表示します。

どちらの経路で動いたかは、記号キーを押すと `cpu=FAST` / `cpu=safe` として出ます。

## 走査線割り込みの確かめ方

ＭＳＸ の走査線割り込み（VDP R#19）は、Ｘ68000 の HSYNC 割り込みで走査線を数えて実現しています。
正しい行で割り込んでいるかは、**割り込みでパレットを書き換えて画面を分割させ、境界の位置を測る**ことで
確かめられます。

`H.KEYI`（$FD9A）に、VDP S#1 を読んで割り込みを下ろし、走査線割り込みなら色を変える処理を
入れてください。**S#1 を読まないと割り込み要求が下りず、割り込みが続けて発生します。**

## 検証済みの範囲

| 検査 | 結果 |
| --- | --- |
| フラグの総当たり（`ADD A,A` 256 通り、`ADD A,C` / `SUB C` / `CP C` 各 65536 通り） | 仕様と一致 |
| `DAA`（Ａ×Ｆ 65536 通り）／`CPI`（Ａ×(HL) 65536 通り） | 仕様と一致 |
| `ADD IX,DE` / `ADD HL,DE` / `ADC HL,DE` / `SBC HL,DE`（各 65536 通り） | 一致 |
| CB 前置きの回転・シフト 8 命令、`BIT` 8 通り、`RES` / `SET`、1 オペランド 9 命令 | オリジナル 0.9.0 と突き合わせて一致 |
| `LDI` / `LDD` / `RLD` / `RRD` / `LD A,I` | 同上 |
| 命令ごとのＴステート計上 | 433 命令すべてオリジナルと一致 |
| `NOFAST` ビルドの実行時間の測定 | 改修前と完全一致 |
| `EDGEALWAYS` ビルドでの実動作 | 905 万回すべての前置き命令を境界経路へ通して正常 |
| `CHECKVKIND` ビルドでの実動作 | 食い違いゼロ |

## オリジナルとの差

| 箇所 | 内容 |
| --- | --- |
| `LD A,R` | 高速経路では命令数を数えないため、Ｔステートの累算から作っています。**オリジナルと値が一致しません。**命令数を数えると全命令に 12 サイクル（約 16%）かかるため、この形にしています |
| 走査線割り込み | 使わないフレームでは HSYNC 割り込みを止めています。そのため**割り込みを有効にした最初の 1 フレームだけ**、割り込みが 1 回遅れます |

## オリジナルから直した箇所

| 箇所 | 内容 |
| --- | --- |
| `RLCA` / `RRCA` / `RLA` / `RRA` | これらは S・Z・P/V を変化させない命令ですが、直前の命令がフラグの評価を遅延させていると、回転後の値から計算し直されていました |
| `IN r,(C)` | F5・F3 が更新されず、以前の値が残っていました |
| 走査線割り込み（212 ライン） | 補正値が 192 ライン専用のまま使われ、20 行遅れて発火していました |
| 走査線割り込み（画面外） | 画面内かどうかの判定が、行番号ではないレジスタを見ていました |
